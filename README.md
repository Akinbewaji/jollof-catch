# Jollof Catch

A fast-paced arcade game built for [start.ng](https://start.ng).

## How to Play
- Slide left and right using touch, mouse, arrow keys, or A/D.
- Catch falling plates of delicious jollof rice (🍛), plantains (🍌), and chicken (🍗) to build your score and streak.
- Dodge the spicy scotch bonnet peppers (🌶️). Three burns and the round ends!

## Features
- Integrates with start.ng accounts and characters (custom styles, hair, accessories, and guest fallback).
- Leaderboard integration with two tracked stats: **Plates caught** and **Best streak**.
- 16:10 cover artwork (`cover.png`).
- Pure static web technology (HTML5 Canvas, CSS, modern JavaScript) with zero external scripts or dependencies.
